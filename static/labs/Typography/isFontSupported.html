mudcu.be › journal › Font detection in HTML5
Checking a few fonts to see whether they're installed…
So you want to detect fonts in a HTML5 webapp? Presenting a fast-native solution for acurately detecting fonts installed on your system — this demo utilizes Javascript and the <canvas> tag and requires a browser that supports ctx.fillFont(), and ctx.getImageData() — including Chrome, Firefox, IE9, Opera and Safari.

Feel free to use “view-source” – the code is CCZero.

How does it work?

1. Determine one font we KNOW is installed on the computer — we need to make sure it’s installed, otherwise we’re going to get ONE false positive in our identification process. I’ve decided to use “Arial” as it’s installed on Windows, Mac, and Linux.

2. Determine some default text to use; I decided to use “TheQuickBrownFox” as it contains asendors, descendors, good letter variation, and is fun to say ;) Now, apply the font style to the canvas:
ctx.font = "100px Arial".

3. Draw the default text to the canvas in the default font:
ctx.fillText().

4. Retrieve the base64 png data from the image:
canvas.toDataURL().

5. Generate a unique hash on the DataURL that can be quickly compared. I chose to use an MD5 hash as the source-code is readily available:
jQuery.md5().

6. Now we have the baseline hash to compare other fonts to. To determine whether a font is installed, repeat the above steps 3-5 using the new font style:
ctx.font = "100px FontYouWantToTest, Arial"

7. Compare the new hash to the default hash — if the hash is different then the font is installed on your system ;-)
